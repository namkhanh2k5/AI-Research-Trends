# Website data readiness — Finalization Phase 2

The local, versioned web-data package is `data/analysis/finalization_p2_web_data_20261101_v3/`. Its read-only validator passed: **22 output files**, **12,000 unique original-sample paper-index rows**, and **14 Topic Briefs**. Output files total 3,643,754 bytes. The package records Phase 3/4/catalogue and topic-snapshot provenance plus output SHA-256 hashes. The future site itself has **not** been built.

The dashboard reuses verified Phase 4 full-population publication trends and separately labeled original-sample citation, OA and collaboration summaries. Topic Briefs include official names/descriptions, scope status, original-sample primary/any-topic counts, sample OA and citation context, related native topics and five most recently published sampled primary-topic papers. “Representative” means recent in this sampled index, not highest quality. The Paper Explorer supports literal title keyword, native-topic, year, type and OA filters, sorting and bounded pagination. All publication text must be HTML-escaped by a future frontend. The deliberately topic-targeted 2,515-work training expansion is absent from these landscape products.

Fourteen bounded live OpenAlex requests on **2026-11-01 07:10:35–07:10:42 UTC** returned **84 validated primary-topic/year counts** for 2020–2025. The source run is `data/analysis/finalization_p2_topic_population_20261101_v2/`, output CSV SHA-256 `3e85a85f32a8583d2b7afee984826199461bf12c4872ec4ace8adcb9eaa56da0`. Each response body, exact `primary_topic.id` query and count validation is retained locally; the earlier failed sandbox-only DNS attempt is preserved as an incomplete local v1 manifest. Counts are explicitly a current OpenAlex-observed snapshot of the approved non-retracted AI/CV frame, **not** the older Phase 4 snapshot and not a sample estimate. The frozen 14-topic ML catalogue was not changed using these results. No API requests are needed at inference or normal website-query time.

The [data contract](../docs/FINALIZATION_P2_WEB_DATA_CONTRACT.md) defines `get_research_overview`, `get_publication_trends`, `get_topics`, `get_topic_brief`, `search_papers`, `get_citation_summary`, `get_oa_summary` and `get_collaboration_summary`. These are local, read-only functions, not a deployed production API. Research Landscape, Topic Explorer, Topic Brief and Paper Explorer have the needed data foundations; Model Inference and evaluation remain Phase 3 work. The actual Git-ignored data package is **not** downloadable from GitHub, so another machine must reproduce or receive it through an approved private data-transfer process.

Remaining limitations: OpenAlex topic taxonomy/classifier drift; sample-only paper and citation/OA/collaboration views; missing abstracts and affiliations; age-dependent citations; no causal OA inference; limited local paper search rather than comprehensive OpenAlex search; no finalized model probabilities or independent human label validity. The site must display source scope, retrieval date and these warnings next to statistics.
