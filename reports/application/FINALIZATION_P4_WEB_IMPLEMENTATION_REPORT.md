# Finalization Phase 4 — web implementation

**Date:** 2026-11-01 UTC. **Status:** Local research explorer implemented and smoke-tested; no public hosting claim.

The six-page Streamlit/Plotly application is `dashboard/app.py`. It consumes the unchanged, checksum-verified Phase 2 web-data package via `ResearchData`; no live OpenAlex request is issued during use. The Home page displays the sample/topic count and full-population publication trend with explicit scope labels. Research Landscape separates RQ1 complete population counts from original-sample RQ2–RQ4 citation/OA/collaboration summaries. Topic Explorer reads all fourteen official Topic Briefs without loading the ML bundle; topic comparison uses the same sample source. Paper Explorer provides literal title search, topic/year/type/OA filters, citation/date sorting, bounded 20-row pages, metadata detail and OpenAlex links; it searches **only the original 12,000-work index**.

Classify My Research validates title and abstract length, loads the trusted Phase 3 bundle only on user action, shows three ranked OpenAlex silver-label topics, status and model version, and requires a distinct explicit user confirmation. SVM margins are not probabilities. `no_confident_match` does not force a placement. Selection remains in browser session memory and does not mutate OpenAlex data. The Methodology page exposes dataset and evaluation boundaries. A separate localhost-only blind reviewer interface supports reviewer A/B, calibration/evaluation, ONE/NONE/UNCLEAR choices, notes, local progress and CSV export; it does not display source labels or predictions.

Local artifact checks before implementation: web-data verifier **22 files, 12,000 paper rows, 14 briefs**; final-ML verifier **14 files, 2025 sealed**; Phase 4 verifier **64 files, 18 checks passed**. Model bundle v2 loaded successfully. Measured on this machine (one cold Python process): verified data load **174.8 ms**, overview query **4.7 ms**, Topic Brief **1.1 ms**, filtered paper search **46.4 ms**, model load **3,438.9 ms**, one inference **14.1 ms**; peak process RSS **385,648 KiB**. A separate RQ4 summary loaded 1,031 country and 18,179 institution edges in **141.2 ms** with peak process RSS **219,128 KiB**. These single-run timings are illustrative, not latency SLAs. Streamlit caches verified data and the trusted model in the running process; paper searches read a small indexed Parquet file on demand. The model is not loaded for manual browsing. A localhost health request returned HTTP 200 in 0.0025 s after server startup.

Security: publication text is rendered as Streamlit text, not untrusted HTML; only static CSS is used with `unsafe_allow_html`. The model path is local and verified before `joblib.load`, but should be trusted anyway. Input is length-bounded. Reviewer ratings and artifact binaries remain ignored by Git. Public deployment is blocked pending approved artifact distribution, metadata rights and secure hosting review. No manual visual browser test was performed; Streamlit AppTest and HTTP health test cover programmatic behavior.
