# Dependencies, governance, CI and deployment

`pyproject.toml` supports Python ≥3.11, an installable src-based package and separate `dev`, `web`, `deliverables` extras. Local `.venv` is Python **3.12.3**. `pip check`: **No broken requirements**. `.venv/bin/python -m pytest -q -ra -o addopts=''`: **205 passed, 1 skipped** in ~16 seconds; skipped test is opt-in live OpenAlex sampling probe. No test was run against the sealed 2025 labels. Exact local artifact verifiers passed: original collection 123 pages, expansion 80 pages, Phase3 29 checks, Phase4 18 checks/64 outputs, integration 8 deterministic hashes, RQ6 13 published outputs, web data 22 outputs, ML closed 14 files, open 23 files, human-review package 2 reviewer packages. These are different scopes of evidence and should not be summed as one test count.

`.github/workflows/ci.yml` on push/PR installs `.[dev,web,deliverables]` in Python 3.12, runs `pip check`, `compileall`, offline pytest and a tracked-secret/data exclusion scan. PR #2 currently shows two successful `test` jobs; PR #1 draft shows no current status rollup. CI checks source and fixture tests. It does **not** restore or verify the local model/web-data package, run the actual site in a browser, inspect DOCX/PDF/PPTX rendering, evaluate 2025, or attest public artifact rights. Local test passage and CI green therefore do not establish end-to-end demo readiness.

At the time of this historical audit, the setup guide provided Ubuntu venv/install and local CLI commands; its current consolidated successor is `docs/REPRODUCIBILITY.md`. `docs/MODEL_AND_DATA_ARTIFACTS.md` lists the web package, model bundle, experiment artifacts and human packages, and points to checksums. `docs/DEPLOYMENT_GUIDE.md` explicitly limits deployment to localhost. The original audit found that a clean clone **could install and run offline tests** but lacked a tested full artifact-restoration path; that was its time-stamped finding, not a current claim. Current Git LFS restoration instructions and the later publication of research artifacts are documented separately in `docs/REPRODUCIBILITY.md`.

The web-data package includes paper metadata and potentially abstracts in private inputs; publication rights and model-bundle distribution require separate review. The local trusted `joblib` loader checks SHA-256 before loading, but checksum does not make untrusted pickle safe. The application binds localhost and normally does not call OpenAlex during browsing. No public hosting, access control, operational monitoring or rollback was observed.
