# Research report index

Start with the [project overview](../docs/PROJECT_OVERVIEW.md), not a historical
handoff. These are the current research entry points; time-stamped stage and
audit reports remain as provenance where they contain distinct evidence.

| Stage | Current entry point | Evidence scope |
| --- | --- | --- |
| Design/Phase 1 | [Feasibility](data_feasibility.md), [pre-collection gate](PRE_PHASE2_REVIEW.md) | Defined AI/CV frame, early API snapshot and sampling decision |
| Phase 2 collection | [Collection report](PHASE2_COLLECTION_REPORT.md) | Original 12,000-work sample and complete population aggregate |
| Phase 3 preprocessing | [Quality report](PHASE3_DATA_QUALITY_REPORT.md) | Eight original normalized Parquet tables |
| Phase 4 EDA | [Academic analysis](PHASE4_ANALYSIS_REPORT.md) | RQ1–RQ4; [published figures](figures/phase4/) |
| Phase 5 reference network | [Final NO-GO decision](PHASE5_FINAL_DECISION.md) | RQ5 citation-recommendation feasibility, not the separate text-search feature |
| Phase 6 topics | [Unified report](phase6/PHASE6_REPORT.md) | RQ6 pilot, expanded validation and integrated ML distinction |
| Final ML development | [Model report](FINALIZATION_P3_FINAL_ML_REPORT.md) | Frozen silver-label model and 2024 development evaluation |
| Final app | [Delivery report](FINALIZATION_P4_FINAL_DELIVERY_REPORT.md), [web guide](../docs/WEB_APPLICATION.md) | Local research explorer and limitations |

The `finalization_p*` reports document **software/integration stages**, not
renumbered original research phases. Their historical snapshots may call the
2025 test sealed; after later publication of labels and keys that independent
seal no longer holds. See [current limitations](../docs/RESEARCH_METHODOLOGY.md).
