# Finalization Phase 3: pre-experiment ML protocol

Declared 2026-11-01 before running new Phase 3 models. The frozen initial label universe is the 14 IDs in `config/phase6b_catalogue.yaml`; target labels are OpenAlex-generated `primary_topic_id` silver labels, **not** independent topic truth. No 2025 label, prediction, class support or metric is used during development. The two-human semantic review is pending, so the final test stays sealed unless that separate gate is resolved.

## Data and features

Use verified `finalization_p2_20261101_v3/train.parquet` (2020–2023) and `validation_2024.parquet` (2024). The closed-set experiment selects only in-catalogue rows; the open-set experiment includes all eligible rows. Model text is `clean_text(title) + "\n" + clean_text(abstract)` using the existing Phase 6A helper, with Unicode preserved. Features are only title/abstract TF-IDF; no topic IDs/scores, year, work type, citations, journal, author or institution enters a predictor. A vectorizer is fitted **inside each training fold**, never on validation. Input work/version groups are unique and checked. The training expansion is used only on the training side; 2024 validation remains the original analytical sample.

## Frozen development design

Baseline B0 is the training-majority topic. B1 is TF-IDF cosine similarity against the 14 verified official descriptions; this uses no paper labels for fitting. Supervised M1 = ComplementNB with `alpha∈{0.5,1,2}`, M2 = LogisticRegression with `C∈{0.3,1,3}`, and M3 = LinearSVC with `C∈{0.3,1,3}`. Shared TF-IDF: word unigrams/bigrams, `min_df=2`, `max_features=50,000`, sublinear TF. Search uses three-fold shuffled `StratifiedGroupKFold`, seed 20251019, scoring fixed-14-class Macro-F1, single-process execution; grouping by version group. Each model is tuned separately under the same training-only protocol for original-only and expanded-data ablations. This is a **tuned-data ablation**, not a pure fixed-hyperparameter causal effect. Additionally refit the strongest model with the same chosen hyperparameter on both training sets as a strict fixed-hyperparameter comparison.

Closed-set 2024 evaluation reports exact denominator, class support, accuracy, Macro-F1, weighted-F1, per-class precision/recall/F1, top-three agreement where meaningful, and confusion matrices. Paired 500-draw example bootstrap with fixed class order, seed 20251019, gives percentile 95% intervals and original-versus-expanded deltas; intervals describe finite validation uncertainty, not sampling-design certainty. No significance claim is based only on a CI crossing zero. The 2024 set has already been inspected in earlier phases, so every result is a **development** result.

For the strongest lightweight model, compare title-only, abstract-only, and combined text using the selected training-only hyperparameter. Also run diagnostic expansion fractions 0, approximately 1/3, 2/3 and all, stratified reproducibly by topic and year, with the same fixed hyperparameter; no extrapolation beyond measured sizes. Report original/expansion composition by year, type, language and abstract length. Do not apply invented inverse-probability weights to targeted expansion.

## Open set and model choice

Use the same trained closed-set LR and SVM, plus a separately trained 15-class LR with a genuine `OTHER` label for historical outside-catalogue works. The 2024 full eligible set is split by version-group hash, stratified by in-catalogue topic versus `OTHER`, with 40% calibration and 60% evaluation; seed 20251019. For each score, choose the **lowest calibration threshold with outside false acceptance ≤20%**; then report the unchanged threshold on the disjoint 2024 evaluation subset. LR maximum class probability is a model probability estimate, not guaranteed calibrated; SVM maximum raw decision margin is **not a probability**. Report AUROC, in acceptance, out false acceptance, accepted-placement precision, selective risk/coverage and end-to-end correct placement over **all** evaluated papers, with exact denominators and bootstrap intervals. No threshold is retuned after evaluating the 2024 evaluation subset. A manual topic choice is a separate user action, not an automatic success.

Select a champion primarily by 2024 closed-set Macro-F1. If models differ by ≤0.01 Macro-F1, prefer lower outside false acceptance at the frozen threshold, then smaller/cheaper inference. Consider per-class failure, calibration and interpretability explicitly. Record a runner-up. This selection is a development decision; it does not imply independent semantic validity. Any post-hoc departure from this rule must be declared.

The champion artifact is fitted on permitted historical train only and packaged with the exact vectorizer, label order, catalogue metadata, chosen score rule, threshold and checksums. Serialized joblib is trusted only after manifest SHA-256 verification; user-provided models are never loaded. The inference contract returns ranked topic suggestions with an explicit score interpretation and `confident_suggestion`/`needs_user_confirmation`/`no_confident_match`, and uses the verified local `ResearchData` Topic Brief package without a live API request.

## Final 2025 gate

Human review must establish no fundamental unresolved catalogue-scope problem; champion, features, hyperparameters, calibration, thresholds and metrics must then be frozen and source hashes rechecked. Only then may a **single** 2025 evaluation run load the sealed file. If human review remains absent or materially unresolved, record `FINAL_TEST_STATUS: SEALED` and do not inspect its labels. The ready-to-run future command must require an explicit authorization/gate artifact, not an ordinary development flag.
